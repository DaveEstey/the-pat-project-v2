# The Pat Project

A game built with Godot.

## Project Structure

- `scenes/` - Godot scenes
- `scripts/` - GDScript source code
- `resources/` - Custom Godot resources and game data
- `shaders/` - Godot shaders
- `assets/` - Art, audio, fonts, models, textures, and UI
- `addons/` - Godot plugins
- `docs/` - Game design and technical documentation

## Development

Use Godot resource paths where possible:

- `res://` for project resources
- `user://` for runtime user data

Avoid machine-specific absolute paths.
